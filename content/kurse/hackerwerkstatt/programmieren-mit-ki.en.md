In the second series, AI itself became a programming partner! Using tools like **Claude Code**, **Lovable**, **Cursor**, and **GitHub Copilot**, participants learned to program together with an AI – from the first prompt to a finished application.

### What did we do?

- Introduction to AI-assisted programming tools (Claude Code, Lovable, Cursor & more)
- Planning and designing websites with AI help (HTML, CSS, JS)
- Debugging and optimising code together with the AI
- Developing your own small app or website
- Writing prompts that actually produce good results
- Understanding the possibilities and limits of AI in everyday coding

### Schedule

1. **Getting to know AI tools** – introduction to Claude Code, Lovable, Cursor, and GitHub Copilot. Formulating useful prompts and understanding how AI helps with coding.
2. **Building websites with AI** – layout, text, colours – all in collaboration between you and the AI, using HTML, CSS, and JavaScript.
3. **Debugging & explaining with AI** – analysing code, improving readability, and automatically adding helpful comments.
4. **Developing your own app with AI** – from idea to application: planning, generating code modules, and using APIs.
5. **Presentation & mini fair** – presenting projects and discussing together how to use AI responsibly.
